# 👑 Trisha Di's Royal Birthday Web App
### *Red Velvet & Noir Gold Edition*

A luxury, interactive birthday celebration web app specially designed with love, pride, and respect **From Mayank**.

---

## ✨ Features

- **Red Velvet & Noir Gold Aesthetics**: Deep rich burgundy and obsidian black backdrop with glass reflections and ambient floating golden dust.
- **Floating 3D Balloons**: Interactive black, golden, and velvet balloons that float upwards and pop with glitter on click.
- **Cute Royal Photo Frame**: Features Trisha Di's highlighted portrait with ornate golden borders, glass floor reflection, photo switcher, and the signature plaque: *"With Endless Love & Respect, from Mayank ❤️"*.
- **Interactive 3D Birthday Wish Card**: Unfolds smoothly on clicking the golden wax seal, triggering real-time fireworks, birthday crackers, and the birthday song.
- **Red Velvet Birthday Cake**: Multi-tiered cake with glowing candles and a cut option that slices the cake, blows out flames, and triggers a massive confetti explosion.
- **Surprise Gift Boxes**: Interactive unboxing reveals:
  - *Gift #1*: "Dark Truth: You are the CUTEST in the whole wide world!"
  - *Gift #2*: "Special Truth: You are the LOVELIEST soul inside & out!"
  - *Gift #3*: "Sister of the Century & Brother's Promise"
- **Her Prettiness & Cherished Memories Gallery**: Complete photo collection and video memory reel celebrating her style, candid smile, and sibling bond.
- **Synthesized Audio Engine**: Built-in Web Audio API that generates the "Happy Birthday to You" melody, cracker pops, knife swooshes, and celebratory fanfares.

---

## 🚀 How to Run Locally

You can open `index.html` directly in any modern browser, or run a local HTTP server:

```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`
